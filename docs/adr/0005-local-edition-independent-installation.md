# 本地补丁版使用独立应用身份安装

- 状态：Accepted（2026-10-21 已随总稿完成用户整体确认；02 已完成独立候选，日常接管与安装仍由后续工单验证）
- 日期：2026-10-20
- 来源：共识访谈 Q19，用户回答「是」

本地补丁版以固定名称 `ZCode Local.app` 独立安装，保留官网下载的 `ZCode.app`；日常使用 Local，后续本地发布仅替换 Local。选择独立身份而非覆盖官方应用，是为了明确两种发布来源、避免替换错应用，并保留官方程序作为参照。

独立身份需要在安装标识、运行时身份及相关集成中保持一致，不能只重命名 DMG。签名、凭据可用性、权限及协议入口的兼容须验证。独立安装不等于业务数据隔离，也不意味着能同时连接同一批机器人或能无条件回退；相关已确认边界见[共识总稿](../local-edition/consensus-summary.md)。

Q20/Q21 后续确认：Local 日常沿用现有业务数据，开发和升级测试隔离；首次切换先备份并验证兼容。应用自身缓存、浏览器登录和窗口状态不承诺全部共用；官网版与 Local 不能同时打开并接管日常数据。因官网版未经修改，互斥保护的双向效果须实测，不能只依赖 Local 私有锁。

Q22 后续确认：Local 关闭官方更新通道，不下载官方包覆盖自身；升级采用获取官方源码、合并补丁、验证并重新打包。首版不建设独立在线更新服务。
